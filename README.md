# Cooked Books — a daily ledger audit puzzle

*by [Vellum Labs](https://github.com/vellumlabs)*

👉 **Play: https://vellumlabs.github.io/cooked-books/**

Some entries in today's ledger are forged. Every entry carries a note. **Genuine entries tell the truth. Forged entries lie.** Read the audited notes, prove which entries are forged, and judge them one by one. One ledger a day, the same for everyone.

- Every ledger has exactly one solution, and at every step at least one entry can be proven by logic alone — no guessing
- Ledgers grow through the week: 4×4 on Monday up to 6×6 at the weekend
- Share your audit as an emoji grid (no spoilers)
- Works on phones and with a keyboard (arrows to move, `G` genuine, `F` forged)
- No account, no tracking, no ads. Progress and streaks stay in your browser
- Past ledgers: add `?d=YYYY-MM-DD` to the URL

## How it is made

| | |
|---|---|
| Code | AI (Claude Code) |
| Graphics / Sound | none generated by AI — everything is CSS |
| Text | note sentences are assembled from templates by the puzzle engine, not written by a language model |

The generator and solver live in [`engine/engine.js`](engine/engine.js) (no dependencies). Each day's ledger is generated from the date, checked for a unique solution, and stored in `data/YYYY-MM-DD.json`. If a file is missing, the page generates the same ledger on your device.
